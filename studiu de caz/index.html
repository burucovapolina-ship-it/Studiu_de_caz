1. Introducere

În prezent, multe proiecte informatice sunt realizate de echipe formate din mai multe persoane. Pentru o bună organizare, membrii echipei au nevoie de instrumente care să îi ajute să comunice și să lucreze împreună.

Git și GitHub sunt instrumente importante pentru dezvoltarea proiectelor. Ele permit păstrarea fișierelor, urmărirea modificărilor și colaborarea dintre programatori.

Scopul studiului: prezentarea modului în care Git și GitHub contribuie la organizarea și realizarea unui proiect comun.

2. Ce sunt Git și GitHub?

Două instrumente diferite, care se completează reciproc.

01

Git

Git este un sistem de control al versiunilor. Acesta înregistrează modificările realizate în fișiere și permite consultarea istoricului proiectului.

02

GitHub

GitHub este o platformă online unde proiectele pot fi păstrate, distribuite și dezvoltate în colaborare cu alți utilizatori.

03

Git Bash

Git Bash permite executarea comenzilor Git pentru crearea proiectelor, salvarea modificărilor și încărcarea fișierelor pe GitHub.

3. Avantajele lucrului în echipă

  • Mai multe persoane pot contribui la același proiect.
  • Modificările fișierelor pot fi urmărite.
  • Codul sursă poate fi păstrat online.
  • Sarcinile pot fi împărțite între membrii echipei.
  • Greșelile pot fi identificate și corectate mai ușor.
  • Proiectul poate fi publicat pe internet.
  • Istoricul permite revenirea la o versiune anterioară.

4. Comenzi Git Bash

Pentru a lucra cu Git, utilizatorul execută comenzi în terminal. Fiecare comandă are un rol concret.

Inițializarea proiectului

git init

Creează un depozit Git în folderul proiectului.

Pregătirea fișierelor

git add index.html

Pregătește fișierul pentru salvarea modificărilor.

Salvarea modificărilor

git commit -m "Adaug pagina HTML"

Înregistrează modificările în istoricul proiectului.

Încărcarea pe GitHub

git push

Trimite pe GitHub modificările locale pregătite anterior.

Comanda git push funcționează după ce repository-ul local a fost conectat la repository-ul online și a fost configurată ramura de lucru.

5. Colaborarea dintre utilizatori

GitHub permite adăugarea altor utilizatori într-un repository. Aceștia pot contribui la proiect în funcție de permisiunile primite.

Administratorul

Creează repository-ul, organizează proiectul și gestionează accesul colaboratorilor.

Colaboratorul

Poate modifica fișierele și trimite contribuții, în limitele permisiunilor acordate.

Verificarea codului

Modificările pot fi discutate și verificate înainte de integrarea lor în proiectul principal.

Cum adăugăm un colaborator?

  1. Deschidem repository-ul pe GitHub.
  2. Intrăm în Settings.
  3. Selectăm Collaborators.
  4. Apăsăm Add people.
  5. Căutăm utilizatorul și trimitem invitația.
  6. Utilizatorul acceptă invitația.

6. GitHub Projects – planificarea sarcinilor

GitHub Projects este un instrument pentru planificarea și urmărirea activităților unui proiect. Acesta poate afișa sarcinile într-un tabel, într-o tablă de tip Kanban sau într-un calendar de tip roadmap.

Planificare

Echipa stabilește sarcinile care trebuie realizate și ordinea acestora.

Organizare

Sarcinile pot fi grupate și repartizate membrilor echipei.

Urmărire

Membrii pot verifica ce sarcini sunt noi, în lucru sau finalizate.

Exemplu de organizare

De făcut

Crearea structurii paginii HTML.

În lucru

Realizarea designului cu CSS.

Finalizat

Verificarea și publicarea paginii.

Prin utilizarea GitHub Projects, membrii echipei își pot organiza mai bine activitățile și pot urmări progresul.

Documentație: Despre GitHub Projects

7. Publicarea paginii web

GitHub Pages este un serviciu care permite publicarea site-urilor web statice. Pentru acest studiu de caz, fișierul index.html este încărcat într-un repository public.

  1. Creăm repository-ul pe GitHub.
  2. Încărcăm fișierul index.html.
  3. Deschidem Settings și apoi Pages.
  4. Selectăm ramura main și folderul /(root).
  5. Apăsăm Save și așteptăm publicarea.
  6. Accesăm linkul generat de GitHub Pages.
Linkul paginii publicate trebuie copiat din secțiunea Pages după finalizarea procesului de publicare.

Documentație: GitHub Pages

8. Studiu de caz practic

O echipă de trei elevi trebuie să creeze un site web. Primul elev realizează structura HTML, al doilea se ocupă de aspectul paginii folosind CSS, iar al treilea verifică informațiile și funcționarea site-ului.

Echipa folosește Git pentru a înregistra modificările și GitHub pentru a păstra proiectul online. Colaboratorii contribuie la fișiere, iar GitHub Projects îi ajută să organizeze sarcinile.

La final, pagina este publicată cu GitHub Pages și poate fi accesată printr-un link.

9. Concluzie

Git și GitHub sunt instrumente importante pentru dezvoltarea proiectelor comune. Git ajută la urmărirea modificărilor, GitHub permite colaborarea online, iar GitHub Projects ajută la organizarea activităților.

Folosirea acestor instrumente economisește timp, îmbunătățește organizarea și facilitează realizarea proiectelor în echipă.
